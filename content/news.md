# News

Edit this file to update the News page.

Format:

```text
- YYYY-MM | Month YYYY | Update text with optional emojis.
- YYYY | YYYY | Update text when the exact month is unknown.
```

Both `-` and `*` bullets work. The important part is the `date | label | text` structure.

Then run:

```bash
python3 scripts/build-news.py
```
